# 4주 온라인 습관화 코칭 통합 대시보드 (Coach Dashboard)

![Version](https://img.shields.io/badge/version-v3.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Web%20%7C%20Google%20Apps%20Script-orange.svg)

참여자(회원)의 사전 설문 인적 사항, 공복 체중 기록, 코칭 지침서(코칭 철학·운동·식단·회원 분석)를 구글 스프레드시트와 연동하고, Google Gemini AI로 맞춤 운동 루틴·식단 생성과 회원별 특이사항 보고(코치 전용)를 하는 **전문 코치용 통합 대시보드 웹 애플리케이션**입니다.

> 운영 방식: 회원은 앱 **기록 탭에서 매일 체중·운동·식단을 기록**하고(구글 폼 대체), 그 밖의 소통은 카카오톡으로 합니다. (`Feedbacks` 시트는 보관용으로만 남아 있습니다.)

---

## 🌟 주요 핵심 기능

### 1. 코치 전용 보안 로그인 & 잠금 장치
- **외부망 배포 보안**: 외부 인터넷 접속 시 미인가자의 데이터 접근을 원천 차단하는 `coachAuthModal`.
- **3회 오류 시 30초 잠금**: 비밀번호 3회 연속 오답 시 30초간 로그인 버튼과 입력창을 비활성화하고 실시간 카운트다운을 표시하여 무차별 대입 공격(Brute-force) 방어.
- **수동 화면 잠금**: 상단 내비게이션 바의 `[🔒 화면 잠금]` 버튼으로 언제든 대시보드를 다시 잠금 처리 가능.

### 2. AI 운동 루틴·식단 생성
- **현재 플랜이 기준**입니다. 회원 상세 루틴·식단 영역에서 `이번 수정 요청`을 적고 **[수정]** 을 누르면 AI가 현재 루틴/식단에서 요청한 부분만 바꾸고 나머지는 그대로 둡니다. **[새로 만들기]** 는 신청서 기준으로 처음부터 만듭니다(회원이 바꾼 내용이 있으면 먼저 확인 창).
- 우선순위: 기본 지침서·안전 원칙 > `고정 조건` > 이번 수정 요청 > 현재 플랜. `운동 고정 조건`·`식단 고정 조건`은 코치만 입력하는 항상 지킬 조건이며 회원에게는 보이지 않습니다.
- AI 결과는 '적용 전' 미리보기로 보이고, **[적용]** 해야 회원 DB에 반영됩니다. 적용하면 이번 수정 요청 칸은 비워지고 내용은 `MemberPlanLog`(요청자 코치)로 옮겨집니다. 그사이 회원이 바꿨으면 덮어쓰기 전에 묻습니다. `최근 수정 이력`에서 누가·언제·무엇을 바꿨는지 볼 수 있습니다.
- 프롬프트는 `gas_backend.js`에서만 만듭니다. AI 실패 시 템플릿 문장을 만들지 않고 실패와 [다시 시도]를 보여 줍니다.

### 3. 회원 일일 기록 (WeightLog · ExerciseList 시트)
- 회원 마이페이지 **`기록`** 탭(홈 `오늘 기록하기`, 상단 `오늘 기록`)에서 날짜를 골라 그날 **체중(선택)·운동·식단**을 한 번에 저장합니다 (오늘 이후 날짜 불가). 이미 기록한 날짜를 열면 기존 값이 채워지고, 그 날 코치 한마디도 함께 보입니다.
- 운동은 `종목 | 횟수 | 세트 | 무게 | 비고` 행으로 입력하고, 종목은 운동 목록 자동완성(초성 검색 `ㅂㅊ` → 벤치프레스)과 **`오늘 루틴 불러오기`** 를 지원합니다. 횟수에는 `12`처럼 숫자나 `30분`·`30초` 같은 시간을 씁니다.
- 운동 칸 위의 **`운동 완료` / `계획된 휴식` / `미계획된 휴식`** 체크박스로 그날 운동 상태를 표시할 수 있습니다(셋 중 하나). 코치 데일리에는 운동 칩 자리에 '운동 완료'(초록)·'계획 휴식'(파랑)·'미계획 휴식'(주황)으로 보이고, AI 회원 분석에도 들어갑니다. 운동 상세 기록과 식단 기록은 선택사항입니다.
- 식단은 아침·점심·저녁·간식 묶음별로 음식과 비고를 입력합니다. 입력 중인 내용은 휴대폰에 임시 보관되어 저장 전에 화면을 닫아도 남습니다.
- 저장 위치는 `WeightLog` 시트(`날짜 | 회원번호 | 이름 | 체중 | 입력자 | 기록시각 | 운동 기록 | 식단 기록 | 운동 요약 | 식단 요약 | 운동 휴식`)이며 **회원번호+날짜 1행**만 유지합니다. `운동 요약`·`식단 요약`은 시트에서 읽기 쉬운 한 줄입니다.
- 체중 그래프·통계(데일리, 회원 상세, 태그별 그래프, AI 분석, 회원 체중 그래프)는 체중이 있는 행만 씁니다.
- `ExerciseList` 시트(`운동명 | 부위 | 상태 | 추가일 | 출처`)가 자동완성 목록입니다. 회원이 목록에 없는 이름을 저장하면 `미등록`으로 쌓이고, 코치가 `등록`으로 바꾸면 자동완성에 나옵니다. 미등록 개수는 대시보드 지침서 화면 위와 시트 메뉴 **`🏋️ 미등록 운동 확인`** 에서 볼 수 있습니다.

### 4. 코치 관리 기록 (CoachLog 시트) — 데일리 · 기록 창
- 대시보드 첫 화면 **`데일리`**: 날짜(◀ ▶·달력)별로 `기록 n/전체`와 회원마다 체중·운동·식단 입력 여부, 그 날 체중(미입력 표시), 7일 평균 추세(그 날까지 7일 평균 − 그 전 7일 평균), 아직 확인 안 한 `다음에 확인`, 기록 여부를 보여 줍니다. 미기록 회원이 위에 오고, 상태(기본 유효)·태그 필터는 회원 목록과 같이 움직입니다.
- 대시보드는 자동으로 다시 불러오지 않습니다. 상단 배지의 **`HH:MM 기준`**(모바일은 시각 + ↻)을 누르면 회원이 방금 저장한 기록까지 바로 불러옵니다. 입력 중인 내용과 열린 기록 창은 그대로 둡니다.
- 회원 줄의 ▾를 누르면 그날 회원이 입력한 운동 표와 식단(아침/점심/저녁/간식)이 펼쳐집니다. 기록 창 위쪽에도 같은 내용이 접힌 상태로 있습니다.
- 회원 줄을 누르면 **기록 창**(모바일: 아래에서 올라오는 창, 데스크톱: 오른쪽 패널)이 열립니다. 식단(좋음/보통/주의)·운동(했음/쉬는 날/안 함) 버튼과 태그, 메모(코치만 봄), 코치 한마디(회원에게 보임, 자주 쓰는 문구 버튼), 다음에 확인을 입력하고 **[저장]** 또는 **[저장하고 다음 →]**(다음 미기록 회원)으로 넘어갑니다. 이전 날짜의 `다음에 확인`은 체크해서 확인 완료 처리합니다.
- 저장 위치는 `CoachLog` 시트(`날짜 | 회원번호 | 이름 | 식단 상태 | 운동 상태 | 식단 태그 | 운동 태그 | 메모 | 코치 한마디 | 다음에 확인 | 확인 완료 | 작성시각 | 수정시각`), **회원번호+날짜 1행**(같은 날 다시 저장하면 덮어쓰기).
- 태그와 자주 쓰는 문구는 `CoachSettings` 시트(`식단 태그 | 운동 태그 | 자주 쓰는 문구`, 아래로 한 칸에 하나씩)에서 직접 고칩니다.
- 회원 상세(모바일 **`기록`** 탭)에서 체중 그래프 아래로 날짜별 기록(코치 기록 + 회원 운동·식단 요약) 타임라인을 보고, 누르면 그 날 기록을 수정합니다. 회원 마이페이지 홈에는 코치 한마디만 보입니다.

### 5. AI 회원 분석 보고 (AnalysisLog 시트, 코치 전용)
- 체중·회원 운동/식단 기록(WeightLog, 운동·식단은 최근 28일)과 코치 기록(CoachLog)을 누적해 AI가 회원별 특이사항을 **코치에게만** 보고합니다. 회원에게 보낼 문장은 만들지 않고, 회원 페이지에는 분석 관련 값이 절대 전달되지 않습니다.
- 기준과 보고 형식은 Guidelines 시트의 **`회원 분석 지침`** (대시보드 지침서 화면 4번에서도 수정)을 따릅니다. 인식하지 못하면 분석하지 않고 오류만 표시합니다.
- 평균·변화율·연속 일수 등 숫자는 코드가 계산해 AI에게 확정값으로 넘깁니다.
- 결과는 `AnalysisLog` 시트(`분석일시 | 회원번호 | 이름 | 특이사항_있음 | 보고`)에 쌓이고 Members `최근 분석`·`분석 일시`가 갱신됩니다.
- 매일 밤 11시 트리거로 유효 회원 전체를 나눠서 분석하고(실패한 회원은 이어 실행에서 재시도), 회원 상세 **`[분석 업데이트]`** 로 한 명만 즉시 분석할 수 있습니다. AI 실패 시 이전 보고는 그대로 두고 '분석 실패'만 표시합니다.
- 데일리에서 특이사항이 있는 회원은 맨 위에 ⚠와 보고 첫 줄로, 회원 상세에는 최근 보고 전문과 이전 보고가 보입니다.

### 6. 태그별 그래프 (회원 비교)
- 상단 **`[태그별 그래프]`** 메뉴(모바일은 하단 **`더보기 → 태그별 그래프`**)에서 태그를 고르면, 그 태그 회원들의 체중을 비교합니다.
  - **체중 (회원별)**: 회원마다 작은 그래프를 따로 그림(각자 눈금, 7일 평균선). 첫 기록 대비 감량 많은 순으로 정렬하고, 카드마다 최근 체중·첫 기록 대비 변화·주당 변화·추세(감소/유지/증가)를 표시.
  - **체중 변화 (비교)**: 첫 기록 대비 변화를 한 그래프에서 겹쳐 비교.
- 가로축은 날짜 또는 참여 일차(회원별 첫 기록일 = 1일차), 휴면 회원 포함 여부 선택. 범례 이름을 누르면 그 회원을 숨김/표시.
- 아래 요약 표(기록 일수, 첫·최근 체중, 변화)는 코드가 계산하며, 이름을 누르면 그 회원의 체중 화면으로 이동.

### 7. 회원 셀프 수정 요청 우선 반영
- 회원이 마이페이지에서 운동/식단 수정을 요청하면 코치 수정 지침보다 **회원 요청을 우선 반영**하고, 코치 지침과 달라진 부분은 '요청 반영 안내'의 **코치님 지침과 다른 부분**으로 알려 줌 (기본 지침서·건강 안전 원칙은 그대로 지킴).
- 코치는 🔔 알림(회원 루틴·식단 변경 알림)과 루틴·식단 패널의 수정 지침 칸 아래 빨간 안내로 확인. 코치가 직접 AI 생성할 때는 기존대로 코치 수정 지침이 최우선.

## 🚀 빠른 시작 및 배포 가이드

### 1. 로컬 실행
별도의 빌드 단계가 없으므로 브라우저에서 `index.html`을 바로 열거나 로컬 웹 서버로 실행합니다.
```bash
# Python 내장 웹 서버 실행 예시
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

### 2. Google Apps Script(GAS) 백엔드 연동
1. 구글 스프레드시트 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. `gas_backend.js` 전체 코드를 복사하여 Apps Script 에디터에 붙여넣고 저장합니다.
3. 스프레드시트를 새로고침한 뒤 상단 메뉴 **`[🤖 코칭 자동화]`** 가 보이는지 확인합니다. (예전 데일리 피드백 폼 트리거가 설치돼 있었다면 **`🧯 폼 제출 트리거 삭제`** 를 한 번 실행합니다.)
4. 상단 **[배포] > [새 배포]** (유형: 웹 앱)를 선택합니다:
   - 다음 사용자 권한으로 실행: `나`
   - 액세스 권한이 있는 사용자: `모든 사용자`
5. 발급된 **웹 앱 URL**을 대시보드 우측 상단 **[⚙️ 설정]** 모달에 입력하고 저장합니다.
6. 예전 Feedbacks 시트의 공복 체중을 옮길 때는 시트 메뉴 **`⚖️ 체중 기록 옮기기`** 를 한 번 실행합니다.
   - 웹앱 입력분은 `MemberPlanLog`의 체중 기록에서, 구글 폼 입력분은 Feedbacks의 이름을 Members 이름과 정확히 맞춰 회원번호를 붙여 옮깁니다 (같은 회원·날짜는 가장 늦게 기록된 값).
   - Feedbacks·MemberPlanLog는 수정하지 않고, WeightLog에 이미 있는 회원·날짜는 건너뜁니다. 옮기지 못한 행은 목록으로 보여 줍니다.
7. 코치 기록을 쓰기 전에 시트 메뉴 **`🧱 코치 기록 시트 준비`** 를 한 번 실행합니다 (CoachLog·CoachSettings 생성, Members 맨 오른쪽에 `체중 목표`·`운동 목적` 열 추가. 이미 있으면 건드리지 않음).
8. 예전 Feedbacks의 코치 한마디를 옮길 때는 **`💬 코치 한마디 옮기기`** 를 한 번 실행합니다 (`피드백 상태`가 '완료'인 행만, 이름을 Members와 정확히 맞춰 회원번호를 붙임. CoachLog에 그 날 한마디가 있으면 건너뜀).
9. AI 회원 분석을 쓰려면 Guidelines 시트에 `회원 분석 지침` 행을 넣고, 시트 메뉴 **`🧠 매일 밤 11시 회원 분석 트리거 설치`** 를 실행합니다 (삭제·지금 전체 분석 메뉴도 있음).
10. 루틴·식단 수정 구조를 바꾼 뒤 한 번 **`📋 수정 지침 정리`** 를 실행합니다. 지금 `수정 제안 지침` 칸에 있는 내용을 회원별로 보여 주고, 항목마다 이력으로만 옮기기 / 고정 조건에 추가 / 그대로 두기를 고른 뒤 실행합니다 (먼저 시트 백업).
11. 회원 기록 탭을 쓰기 전에 시트 메뉴 **`🏋️ 운동 목록 초기 등록`** 을 한 번 실행합니다 (ExerciseList 생성·기본 종목 + 회원 루틴 종목 등록, WeightLog 맨 오른쪽에 기록 열 5개 추가. 여러 번 실행해도 중복 없음).

### 3. GitHub Pages를 통한 외부망 웹 배포
본 저장소에는 GitHub Pages 자동 배포 워크플로우가 구성되어 있습니다.
1. GitHub 저장소의 **Settings > Pages** 메뉴로 이동합니다.
2. **Build and deployment > Source**를 **GitHub Actions**로 선택합니다.
3. 코드가 `main` 브랜치에 푸시되면 자동으로 전 세계 어디서나 접속 가능한 HTTPS 웹 배포가 완료됩니다!

## 🔒 보안 아키텍처 및 비밀번호 관리

본 프로젝트는 프론트엔드 자바스크립트(`app.js`)에 **평문 비밀번호를 일절 보관하지 않습니다.**
- **구글 백엔드 검증**: 실제 비밀번호는 외부 브라우저나 GitHub에서 절대 볼 수 없는 **Google Apps Script(GAS) 구글 서버 [스크립트 속성(`COACH_PASSWORD`)]**에만 안전하게 보관됩니다.
- **오프라인 단방향 해시(SHA-256)**: Mock 모드 시에도 복호화가 불가능한 SHA-256 해시값으로만 비교되므로 GitHub 공개(Public) 저장소에 소스코드가 올라가도 비밀번호가 노출되지 않습니다.
- **초기 기본 비밀번호**: `coach1234!`
- **비밀번호 변경 방법**:
  - 구글 스프레드시트 상단 메뉴 **`[🤖 코칭 자동화] > [🔑 코치 마스터 비밀번호 설정/확인]`**을 클릭하여 클릭 한 번으로 새 비밀번호를 등록할 수 있습니다. (웹앱 코드 재배포 불필요)
- **화면 잠금**: 공용 PC나 외부 접속 후 우측 상단의 `[🔒]` 버튼을 누르면 즉시 보안 인증 상태로 전환됩니다.
- **회원 DB 비공개 (서버 토큰 인증)**:
  - 코치 로그인 성공 시 GAS 서버가 30일짜리 서명 토큰을 발급하며, 시트 조회(`getAll`)·저장·AI 생성 요청은 모두 이 토큰이 있어야만 처리됩니다. 비밀번호를 변경하면 기존 토큰은 자동 만료됩니다.
  - 회원 마이페이지는 `getMemberView` API로 휴대폰 뒷 4자리를 **서버에서** 검증한 뒤 본인 데이터만 받습니다 (코치 지침·연락처 열 제외, 체중은 WeightLog의 본인 회원번호 행만, 코치 기록은 본인 행의 날짜·코치 한마디만). 5회 연속 오류 시 10분간 잠깁니다.
  - 휴대폰 번호가 등록되지 않은 회원은 인증할 수 없으므로 Members 시트에 연락처를 반드시 입력해 주세요.
  - 토큰 서명키는 스크립트 속성 `COACH_TOKEN_SECRET`에 자동 생성됩니다. 이 값을 지우면 모든 코치/회원 로그인이 1회 초기화됩니다.
- **회원 셀프 수정 (AI 재생성)**:
  - 회원 마이페이지에서 운동 루틴/식단 '수정 요청'을 입력하고 AI로 다시 만들 수 있습니다 (종류별 하루 3회, AI 실패 시 횟수 미차감).
  - AI는 현재 플랜을 기준으로 요청한 부분만 바꿉니다. 우선순위: 기본 지침서·안전 원칙 > 고정 조건 > 회원 요청 > 현재 플랜. 고정 조건 때문에 반영하지 못한 부분은 '요청 반영 안내'에 이유만 짧게 알립니다. 지침서·고정 조건은 서버에서만 읽으며 회원은 볼 수도 수정할 수도 없습니다.
  - 데일리 회원 줄에 '루틴 셀프 수정'·'식단 셀프 수정' 칩이 표시됩니다.
  - Members 시트에 `회원 운동 요청`, `회원 식단 요청`, `이전 버전(운동)`, `이전 버전(식단)`, `회원 운동 변경일시`, `회원 식단 변경일시` 열이 처음 사용 시 자동 추가됩니다.
  - 결과는 즉시 반영되고 코치 대시보드 🔔 알림에 표시되며, 회원은 마이페이지 버튼으로 이전 버전으로 되돌릴 수 있습니다(코치가 적용한 뒤에는 되돌릴 이전 버전이 비워집니다).
  - 수정 요청은 최대 1000자입니다.
  - **다른 회원 오기록 차단**: 저장 직전에 잠금을 걸고 회원번호·휴대폰 뒷자리로 본인 행을 다시 찾아 정확히 1개일 때만 기록합니다(AI 생성 중 시트 정렬·행 삽입/삭제에도 안전). 회원번호/이름이 중복된 행이 있으면 코치 저장·회원 수정 모두 중단됩니다. 모든 회원 셀프 수정은 `MemberPlanLog` 시트에 이력이 남습니다.
